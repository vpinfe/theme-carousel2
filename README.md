# Carousel2

A single screen theme for a desktop.  The top four fifths of the screen show the table's cabinet picture on the left and a large picture of the table beside it.  A row of wheels runs along the bottom with the selected one in the middle, larger and fully lit.

![Carousel2 on a desktop](preview.png)

A table with no picture of the kind being shown is named where the picture would be, and a table with no wheel is named in the row.

## Install

Open Themes in the Console, find Carousel2, and press Install.  Then press Make Active and restart VPinFE.  It needs VPinFE 3.0 or later.

## Settings

These are on the Themes page in the Console, under Carousel2's settings.

| Setting | What it does |
| --- | --- |
| Main Image | The large picture of the selected table: the backglass, full single screen, playfield, wheel, cabinet or score view.  The backglass by default.  If you set this in VPinFE 2.x, your choice carries over. |
